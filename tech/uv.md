# uv

## What it is

uv is a command-line tool, written in Rust, that does the jobs of several Python packaging tools quickly. In this repository it does exactly one job: it **compiles** the list of libraries in `pyproject.toml` into the fully pinned lock files, by working out which exact versions satisfy all the rules. This repository used **uv 0.11.2**. uv is not needed to install or run the project; it is used only when you want to change the lock files.

## Why this repository uses it

`pyproject.toml` says "boto3 at least 1.35 and below 2". That is a range. A reproducible build needs one version per library, plus hashes. uv finds a consistent set (the **resolution**) and writes it down, hashes included.

## Where it appears

| Path | What it does with uv |
| --- | --- |
| `requirements.lock` | generated by `uv pip compile` (first line says so) |
| `requirements-dev.lock` | generated by `uv pip compile --extra dev` |

## How it works underneath

uv reads the dependency ranges from `pyproject.toml`, asks PyPI for the available versions and each version's own requirements, and picks versions that fit everyone. `--universal` makes the result valid for all operating systems and Python versions at once (it adds conditions such as `; sys_platform == "win32"` where a library differs). `--generate-hashes` adds the SHA-256 fingerprints of every downloadable file for each chosen version.

## Walkthrough of this repository's use

The lock file records the command that made it:

From `requirements-dev.lock`:

```text
# This file was autogenerated by uv via the following command:
#    uv pip compile pyproject.toml --extra dev --universal --generate-hashes --python-version 3.12 -o requirements-dev.lock
```

- `uv pip compile pyproject.toml`: read the dependency list from this file.
- `--extra dev`: also include the optional group named `dev` (`[project.optional-dependencies]`). `requirements.lock` is made without this flag, so it holds only run-time libraries.
- `--universal`: produce one result valid on every platform.
- `--generate-hashes`: add fingerprints.
- `--python-version 3.12`: resolve for Python 3.12, the oldest version the project supports, so the result also works on newer ones.
- `-o requirements-dev.lock`: write the result to this file.

To update the locks, run both commands again (one with `--extra dev`, one without), review the diff, and run `make lint test`.

### Every entry of the lock files, one by one

A **lock file** is the full, exact list of libraries that the project installs, including the libraries that its libraries need. Each entry has the same parts:

- `name==version`: the library and the one version that is installed. `==` means "exactly".
- `; sys_platform == 'win32'` (only on some entries): an **environment marker**. The library is installed only where the condition is true, here only on Windows. Because the lock was made with `--universal`, it holds entries for every platform, and a marker says where each applies.
- `--hash=sha256:...` lines: fingerprints (SHA-256, a number that is computed from a file's bytes) of every file that may be installed for this version. With `pip install --require-hashes`, pip refuses any file whose fingerprint is not in the list, so a replaced or tampered download is rejected. There are several because a library is published as several files (one for each Python version and operating system).
- `# via x` comment lines: which other library asked for this one. `# via cloud-security-... (pyproject.toml)` means this repository asked for it directly. A list under `# via` means several libraries asked.
- The first two comment lines record the exact command that created the file, so the next person can repeat it.

## Try it yourself

```bash
uv --version
```

Expect `uv 0.11.2` (or newer).

```bash
head -n 2 requirements-dev.lock
```

Expect the "autogenerated by uv" line and the command.

```bash
uv pip compile pyproject.toml --universal --python-version 3.12 -o /tmp/preview.lock && grep -c "==" /tmp/preview.lock
```

Writes a lock without hashes to a temporary file and counts the pinned libraries: 7 (boto3, botocore, jmespath, python-dateutil, s3transfer, six, urllib3). It needs network access.

## Mistakes people make

- Compiling on a newer Python than the minimum, and getting a lock that a 3.12 machine cannot use. The `--python-version 3.12` flag prevents that.
- Hand-editing a `.lock` file. The next compile overwrites it.
- Assuming a range in `pyproject.toml` means every machine gets the same version. Only the lock gives that.

## Check yourself

1. What does `uv pip compile` produce? *A fully pinned, hashed list of requirements.*
2. What does `--extra dev` add? *The optional `dev` group of libraries (pytest, ruff and the rest).*
3. Why `--universal`? *One file valid on all operating systems.*
4. Is uv needed to install the project? *No. pip installs from the lock; uv only regenerates it.*
5. Where is the command that made a lock recorded? *In the first two lines of the lock file.*
